# capstone_3d

Source code for the COLMAP and MapAnything capstone experiments.

This repository intentionally excludes datasets, generated experiment outputs,
COLMAP binaries, model weights, and the MapAnything repository.

Expected local structure:

- scripts/
- data/
- tools/COLMAP/
- tools/map-anything/
- experiments/
- colmap_output/
- mapanything_output/

The missing runtime folders must be installed or transferred separately.
The experiment runner is intended for native Windows Python/Conda.
